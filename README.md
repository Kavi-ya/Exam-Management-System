
# 🎓 Exam & Result Management System

A dynamic web-based application for managing online examinations and student results in educational institutions. Designed for admin and student interactions, this system ensures smooth handling of question banks, student records, exam sessions, and result management using JSP, Servlets, and JSON file storage.

## 📌 Features

- 🧑‍💼 Admin Login to manage exam questions and student results
- 🧑‍🎓 Student Login to view available exams and results
- 🗂️ Dynamic question management with CRUD operations
- 💾 JSON-based file handling for exam and student data
- 🔐 Secure authentication for admin and student roles
- 🎨 Responsive UI using Bootstrap

## 🧑‍💻 Getting Started

### 📦 Prerequisites

- Java JDK 8 or later
- Apache Tomcat 9 or later
- IntelliJ IDEA or Eclipse IDE
- Git

### ⚙️ Steps

1. Clone the repository:

```bash
git clone https://github.com/Kavi-ya/Exam-Management-System.git
```

2. Import the project into **IntelliJ IDEA** or **Eclipse** as a **Dynamic Web Project**.

3. Ensure that the `data/` folder contains:
   - `users.json`
   - `questions.json`
   - `results.json`

4. Configure and deploy the project on **Apache Tomcat**.

5. Run and access the system at:  
   `http://localhost:8080/Exam-Management-System/`
